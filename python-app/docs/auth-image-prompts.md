# Ilustrações de autenticação

Geradas com a ferramenta integrada de imagens (skill imagegen). PNGs originais com transparência em `frontend/images/auth-login-v1.png` e `frontend/images/auth-signup-v1.png`.

## Especificação compartilhada

Use case: illustration-story. Asset type: production illustration for the authentication page of a friendly Portuguese conversational app, Trash Talker. Style: sophisticated playful flat editorial illustration with rounded organic forms, crisp cocoa-brown outlines, light paper grain within the colored shapes, slightly hand-drawn finish, no 3D, no photorealism. Palette strictly warm golden yellow #F7D834, terracotta orange #EB6A40, dark cocoa #2D1D1A, cream #F4F5EF and warm tan. Centered square composition with generous transparent margins, all subjects fully visible. Actual transparent background, suitable for cream and dark cocoa page backgrounds. No letters, no text, no UI forms, no logos, no watermarks.
